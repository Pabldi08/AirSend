Envía el audio de Windows a tu HomePod

    Experimental: al conectar otro receptor durante la reproducción, se añadirá al audio actual. Los receptores pueden no estar perfectamente sincronizados.

    Fuente de audio de Windows

    Captura las aplicaciones que reproducen en esa salida. No redirige las aplicaciones a otro dispositivo.

    Se prueba mientras llega audio. Si el silencio corta la captura, se restaura la salida. Se restaura también al parar.

    Parejas y sincronización (experimental)

    Selecciona dos HomePods para probar un reloj y envío compartidos. Requiere PTP en la red. Si se pierde un miembro, se para todo el grupo.

    Puede reducir el retardo, pero también causar cortes. Para cambiarlo, para la reproducción. El HomePod puede añadir su propio retardo.

    Menos retardo Más estabilidad

    Confirma el cambio para aplicarlo. Solo puedes cambiarlo una vez cada 10 segundos. Si se está reproduciendo audio, la conexión se reinicia brevemente; los valores bajos pueden causar cortes.

    Diagnóstico de audio

    Descarga las métricas de las últimas sesiones para comparar retardo y cortes. No incluye nombres, direcciones IP ni credenciales. Las medidas locales no representan el retardo audible del HomePod.

    ¿No aparece tu HomePod? Añade su IP manualmente

    Algunos routers (Movistar HGU, redes con VLANs) no propagan mDNS entre wifi 2.4 y 5 GHz. Mira la IP del HomePod en la app Casa del iPhone.
